One front page that sums up the world news of Monday 23 November 2026: the AI-stock rout in Asia, Indonesia's factory fire, NATO's emergency talks on Russian missiles in Poland, Ukraine, COP31's failure, India, a deep Vanuatu quake and Australia's jobs warning. `draw.py` (Pillow) draws `entry.png` deterministically; `main.ts` copies it to the output directory using only the Node standard library.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts   # writes ./out/entry.png
python3 draw.py                         # optional: redraw entry.png (needs Pillow + Noto fonts)
```
